# 갑옷 속의 유령 (ghost-game)

2D 픽셀 횡스크롤 액션 로그라이트. 현재 4단계까지 구현: 투구 4개 · 적 4종 · 시작 방 → 전투 3 → 상점 → 전투 2 · 보상 문 선택(금화/상자/투구/쇳조각) · 아이템 20개(녹슨·단련된·명품) · 문장 6개 · 빙결/출혈/화상 · 방 프리팹(넓은 방, 높낮이 있는 지형, 단방향 발판, 카메라, 원근 배경) · 캐릭터 창.

보이드 몸은 Blender로 만든 3D 모델을 도트로 변환한 스프라이트(`assets/void_*.png`)다. 다시 뽑으려면:

```bash
blender -b -P art/void/void_blender.py -- /tmp/voidr
```

```bash
python3 art/void/void_pixelate.py /tmp/voidr assets
```

## 실행

`index.html`을 브라우저로 열면 된다 (빌드·설치 없음). `assets/` 폴더가 같이 있어야 배경과 보이드가 나온다.

## 조작

| 행동 | 키 |
| --- | --- |
| 이동 | ← → |
| 점프 (2단) | C |
| 대시 (2회 충전) | Z |
| 기본 공격 | X |
| 스킬 1 / 2 | A / S |
| 투구 교체 | Space |
| 줍기 · 문 · 구매 | ↑ |
| 발판 아래로 내려가기 | ↓ + C |
| 캐릭터 창 | Tab |
| 다시 시작 | R |

## 투구 추가

`index.html`의 `HELMETS` 배열에 항목 하나를 더 넣으면 방 클리어 보상으로 등장한다. 처음부터 쓰려면 `reset()`의 `slots`에 그 `id`를 넣는다.

## 적 · 방 추가

적은 `ENEMIES`에, 방 순서와 웨이브 구성은 `ROOMS`에, 방 모양(너비·솟은 땅·발판·스폰 자리)은 `LAYOUTS`에 항목을 더 넣는다.
