# 갑옷 속의 유령 (ghost-game)

2D 픽셀 횡스크롤 액션 로그라이트. 현재 2단계(투구 4개 · 적 4종 · 웨이브 전투 방 3개 · 투구 보상)까지 구현.

## 실행

`index.html`을 브라우저로 열면 된다 (빌드·설치 없음). `assets/bg_burning_village.png`가 같은 폴더 구조에 있어야 배경이 나온다.

## 조작

| 행동 | 키 |
| --- | --- |
| 이동 | ← → |
| 점프 (2단) | C |
| 대시 (2회 충전) | Z |
| 기본 공격 | X |
| 스킬 1 / 2 | A / S |
| 투구 교체 | Space |
| 줍기 · 문 | ↑ |
| 다시 시작 | R |

## 투구 추가

`index.html`의 `HELMETS` 배열에 항목 하나를 더 넣으면 방 클리어 보상으로 등장한다. 처음부터 쓰려면 `reset()`의 `slots`에 그 `id`를 넣는다.

## 적 · 방 추가

적은 `ENEMIES`에, 방과 웨이브 구성은 `ROOMS`에 항목을 더 넣는다.
