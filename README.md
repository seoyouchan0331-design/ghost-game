# 갑옷 속의 유령 (ghost-game)

2D 픽셀 횡스크롤 액션 로그라이트. 현재 1단계(조작·투구 2개·민병 3마리)까지 구현.

## 실행

`index.html`을 브라우저로 열면 된다 (빌드·설치 없음). `assets/bg_burning_village.png`가 같은 폴더 구조에 있어야 배경이 나온다.

## 조작

| 행동 | 키 |
| --- | --- |
| 이동 | ← → |
| 점프 (2단) | C |
| 대시 (2회 충전) | Z |
| 기본 공격 | X |
| 스킬 1 / 2 | A / S |
| 투구 교체 | Space |
| 다시 시작 | R |

## 투구 추가

`index.html`의 `HELMETS` 배열에 항목 하나를 더 넣고, `reset()`의 `slots`에 그 `id`를 넣으면 된다.
